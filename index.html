PDF Toolkit
🔒 100% client-side · files never leave your device

Organize PDF

Drag pages to reorder, rotate or delete them, and add pages from other PDFs. Then export the result.

Merge PDFs

Combine several PDFs into one. Drag the rows (or use the arrows) to set the order.

Split PDF

Cut a PDF into pieces by page ranges, fixed-size chunks, or single pages.

Compress PDF

Reduce file size. Strong modes re-render pages as images (text becomes non-selectable); "Optimize only" keeps everything intact.

PDF → Flipbook

View a PDF as a page-turning book. Zoom with the slider, Ctrl+scroll, or double-click; drag to pan.

Image → PDF

Turn JPG, PNG, WebP, GIF or BMP images into a single PDF — one image per page.

HTML → PDF

Paste HTML or open an .html file, preview it, and save as PDF. Scripts are disabled and remote resources are blocked, so embed images as data URIs.
